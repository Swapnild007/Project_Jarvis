# JARVIS Career OS

A personal Career Operating System for the 29 November 2028 career pivot: Cybersecurity → Security Engineering → AI/LLM/Agent Security.

## Architecture
- Frontend: React + TypeScript
- Backend: Node/TypeScript API
- Database: SQLite for local-first development, with a clean repository layer for later managed DB migration
- Shared Career State: single source of truth
- Skill Graph: dependency-driven capability model
- Mission Engine: state-driven next-mission selection
- Tests: unit and integration coverage from the beginning

## Build principle
Assess → Plan → Learn → Practice → Lab → Build → Break → Fix → Assess → Prove → Document → Recalculate → Advance.

JARVIS must never assume a single technology is always next. Python is one skill inside Engineering.
