# JARVIS Python Career Centre

The Python Career Centre is the first full learning track inside Module 05, Learning / Teaching OS.

## Learning contract

Every lesson follows:

1. Learn one focused concept.
2. Inspect a practical example.
3. Complete a recall/design exercise.
4. Submit an explanation or code-oriented answer.
5. Receive an evidence score.
6. Record evidence into Career State when the completion gate is met.
7. Continue to the next lesson or retry.

Completion threshold: 60/100.

## Curriculum

22 lessons from Python fundamentals through APIs, testing, pandas, automation, defensive security automation and a career capstone.

## Career alignment

The curriculum deliberately uses WFM/RTA, automation and defensive-security examples. The end state is not simply "knows Python". The target is demonstrated ability to build maintainable automation and security tooling.

## State

Progress is persisted through the existing JARVIS local Career State under `state.learning`, while Python skill evidence is written to the existing `skills.python` record and Module 05 evidence.
